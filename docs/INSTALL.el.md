# SEISMO v1.1.0 · Εγκατάσταση μέσω cPanel

1. Στο **File Manager**, άνοιξε τον υπάρχοντα φάκελο `seismo/` στο Document Root του `dos.gr` και κράτησε αντίγραφο των σημερινών αρχείων.
2. Ανέβασε το `SEISMO-v1.1.0-cPanel.zip` μέσα στο `seismo/` και επίλεξε **Extract** στον ίδιο φάκελο. Το ZIP έχει το `index.html` και το `stations.txt` στη ρίζα και τα αγγλικά στο `en/index.html`. Επίτρεψε την αντικατάσταση των αντίστοιχων αρχείων της παλιάς έκδοσης.
3. Άνοιξε [Ελληνικά](https://dos.gr/seismo/) και [English](https://dos.gr/seismo/en/). Έλεγξε ότι ο κατάλογος εμφανίζει **1.1.0**, η εναλλαγή γλώσσας λειτουργεί και ενεργοποιείται το SPIN. Αν παρεμβάλλεται προσωρινή αποθήκευση, καθάρισε τις σχετικές καταχωρίσεις μόνο για το `/seismo/`.
4. Προαιρετικά, έλεγξε αν ο server προσθέτει δικό του `X-Robots-Tag` ή χρησιμοποιεί `robots.txt` που αποκλείει τη διαδρομή. Οι κύριες HTML σελίδες του πακέτου επιτρέπουν ευρετηρίαση, με canonical και sitemap στις επίσημες διευθύνσεις.

Το πακέτο χρειάζεται μόνο στατική φιλοξενία HTTPS. Για τοπική δοκιμή, σέρβιρε τον φάκελο εφαρμογής από localhost με έναν στατικό server. Ο κατάλογος ενημερώνεται μέσω `stations.txt`. Βλ. [αλγόριθμο](../ALGORITHM.md), [αποτελέσματα και όρια παρόχων](PHASE-9.el.md) και [άδειες](../NOTICE.md).
