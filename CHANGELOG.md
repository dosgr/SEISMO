# Changelog / Ιστορικό εκδόσεων

## 1.0.0 — Initial Public Release

- First public GitHub distribution of the Phase 5 browser application. The distributable pages and runtime retain their Phase 5 bytes.
- Greek and English frontends, editable source, station catalog, archival demonstration, and public result verification.
- Bilingual documentation, release packaging, and separate attribution for third-party datasets and assets.

## 1.0.0 — Πρώτη δημόσια έκδοση

- Πρώτη δημόσια διανομή στο GitHub της εφαρμογής browser της Φάσης 5, με αυτούσια HTML και κώδικα εκτέλεσης.
- Ελληνική και αγγλική έκδοση, επεξεργάσιμος κώδικας, κατάλογος σταθμών, αρχειακό παράδειγμα και δημόσιος μηχανισμός επαλήθευσης.
- Δίγλωσση τεκμηρίωση, πακέτο έκδοσης και αναφορά προέλευσης δεδομένων και στοιχείων τρίτων.
